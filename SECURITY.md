# Security Policy

## Reporting a vulnerability

Please do not publish suspected vulnerabilities as public GitHub issues.

Send vulnerability reports to **contact@battlereef.com** with the subject line **Security Vulnerability Report**. Include the affected route or component, reproduction steps, observed impact, and any supporting evidence that can be shared safely.

BattleReef will prioritize reports that affect confidentiality, integrity, availability, authentication, authorization, deployment integrity, or the security of connected marine systems.

## Scope

This repository contains the public BattleReef website. Vulnerabilities in the BattleReef Marine Controller should be reported against that project's security process rather than disclosed publicly here.

## Supported version

The current production version on the `main` branch is the supported version.
