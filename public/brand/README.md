# BattleReef canonical logos

The authoritative BattleReef identity uses the circular wave in both approved variants:

- `battlereef-logo-mark-v2-*`: circular wave and “B” emblem for compact, icon, favicon, and initial-mark placements.
- `battlereef-logo-full-v2-*`: circular wave and “B” emblem followed by the BattleReef name for headers, footers, branded panels, metadata, and wide placements.

All negative space and enclosed counters in both variants must remain transparent so the surrounding page background shows through. Do not introduce white fills or place the canonical logo on a white or near-white panel.

The standalone “B + BattleReef” wordmark without the circular wave is obsolete and must not be used in new work.

Earlier non-`v2` raster exports are retained only for cache compatibility. They are deprecated and must not be referenced by page code or metadata.

Use the responsive WebP variants through `src/BrandLogo.jsx`; do not reference uploaded source filenames directly.
