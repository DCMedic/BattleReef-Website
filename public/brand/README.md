# BattleReef canonical logos

The authoritative BattleReef identity uses the circular wave in both approved variants:

- `battlereef-logo-mark-*`: circular wave and “B” emblem for compact, icon, favicon, and initial-mark placements.
- `battlereef-logo-full-*`: circular wave and “B” emblem followed by the BattleReef name for headers, footers, branded panels, metadata, and wide placements.

The standalone “B + BattleReef” wordmark without the circular wave is obsolete and must not be used in new work.

Use the responsive WebP variants through `src/BrandLogo.jsx`; do not reference uploaded source filenames directly.
